# 准备模式完整流程（地产建筑设计管理岗）

## 输入要求
- JD（必要）
- 个人简历（必要）
- 面试轮次（必要——决定策略重点）
- 公司背景补充资料（可选，用户提供）

---

## Step 1: JD 分析
提取以下信息：

### 显性要求
- 岗位名称、汇报对象（向设计总监 / 工程副总 / 区域总汇报）、负责项目类型与业态（住宅 / 商业 / 办公 / 综合体）、项目数量
- 硬性技能要求：方案把控 / 施工图把控 / 专业背景（建筑学 / 结构）、项目类型经验（刚需 / 改善 / 高端 / 商业）、报批报建经验、标准化 / BIM / 绿建等
- 软性要求：跨部门协同、成本意识、进度把控、经营思维

### 隐性需求
- 这个岗位是新设还是替补？→ 新设意味着要搭体系 / 建标准，替补意味着要延续已有风格与流程
- 为什么现在招人？→ 新项目上马 / 项目拓展 / 补位 / 建体系 / 地产行业优化后补强
- JD 中反复出现的关键词 → 面试官最看重的点

### 岗位真实画像
用一句话总结这个岗位实际要解决什么问题。JD 写的是"负责项目设计管理工作"，背后可能是"找一个人把项目从拿地到交付的设计管起来、压住设计院、管住进度与成本、别再超限额"。

---

## Step 2: 轮次策略匹配
> **核心原则：** 每轮面试的考核重点完全不同。用同一套策略打所有轮次是最高频的错误。

| 轮次 | 面试官典型角色 | 考核重点 | 准备策略 |
|------|--------------|---------|---------|
| **初面** | HR / 设计总监 / 专业总工 | **专业能力验证、项目经验真实性、基础匹配度** | 深挖每个项目（业态 / 指标 / 你的角色 / 你解决过的难题），准备 STAR；准备离职原因、动机等基础问题；先把"怎么做"讲清楚，不要过度讲战略 |
| **中间面（二三面）** | 工程总 / 成本总 / 营销总 / 投资总、区域设计负责人 | **复杂问题解决、跨部门协同、产品与市场理解** | 准备跨部门协同真实案例（成本 / 工程 / 营销 / 投资）；展示产品判断与经营视角；准备好"你怎么看 XX 产品趋势" |
| **终面** | 区域总 / 城市总 / 分管副总 | **产品战略、体系化能力、格局** | 少讲单个项目细节（容积率 / 图纸）；多用分层框架；展示体系化能力（怎么搭设计管理体系）；准备好反问高管的问题 |

### 跨轮次进阶逻辑
```
初面：证明"你能管"（管住设计院、管住进度/质量/成本）
  → 中间面：证明"你还能协同 + 懂产品"（跨部门、产品与市场判断）
    → 终面：证明"你还能看"——看行业、看产品战略、看体系
```

## Step 3: 公司研究
引导用户回答以下问题（不需要深入调研，5 个问题每个写 2-3 句即可）：

1. **这家公司靠什么赚钱？**（开发模式是什么：高周转快销型 / 产品力溢价型 / 持有运营型？主流业态是住宅 / 商业 / 办公 / 综合体？）
2. **它在产业链什么位置？**（土地—开发—销售—交付链条中，核心壁垒在哪：拿地能力 / 融资 / 产品 / 运营？）
3. **核心竞争对手是谁？这家跟对手比怎么样？**（产品 / 口碑 / 去化能力）
4. **目前最大的痛点是什么？**（市场下行 / 去化压力 / 利润下滑 / 融资受限 / 项目拓展困难？）
5. **这个岗位为什么现在招人？**（新项目上马 / 项目拓展 / 补位 / 建体系 / 标准化？）

---

## Step 4: 问题预测
结合 JD + 轮次 + 公司背景，按以下几个大类预测问题：

### 必问题（任何轮次都可能问）
- 自我介绍
- 为什么离开上一家公司
- 为什么选我们
- 期望薪资

### 轮次重点问题

**初面重点：**
- 深挖简历项目（你在 X 项目具体负责什么？业态 / 指标 / 你的角色 / 你解决过什么难题？）
- 专业知识考察（什么是容积率 / 得房率？说说设计管理全流程 / 图纸会审 / 限额设计）
- 行为类问题（说一个你解决的设计难题 / 一个设计变更的冲突处理）

**中间面重点：**
- 行业 / 产品认知（你怎么看当前产品趋势？改善型需求怎么抓？）
- 复杂问题（成本与品质怎么平衡？标准化与定制化怎么统一？设计院怎么管才高效？）
- 协作类（你跟成本部 / 工程部 / 营销部发生过冲突吗？怎么解决？）

**终面重点：**
- 战略类（如果让你来负责设计条线，你第一步做什么？）
- 格局类（地产行业 3 年后格局如何？设计管理在其中的价值？）
- 方法论类（你做成本优化用什么方法？怎么搭设计管理体系？）
- 定义类（什么是产品力？什么是好的户型？）
- 压力测试类（你期望薪资偏高 / 你项目经验不够全业态）

### 基于公司背景的定制问题
- 如果是竞品公司，必问："你跟 XX 的产品体系比，优势是什么？"
- 如果是转型期 / 困难期公司，必问："你进来怎么用设计帮项目去化 / 降本？"
- 如果是高周转公司，必问："你怎么在极短周期内保证设计进度和图纸质量？"

---

## Step 5: 作答策略
针对预测的问题，提供回答框架。具体参考 `references/question-frameworks.md`。

### 核心提醒
- 定义类问题 → 三段式定义法："我的理解是……举个例子……所以对我来说……"
- 行为类问题 → STAR + 方法论提炼："当时背景是……我用的方法是……结果是……"
- 认知类问题 → 观点先行："我认为……有三个原因……"
- 不知道答案 → 拉升维度："这个问题背后涉及到……我从这个角度来回答……"

## 输出物模板
准备模式的最终输出是一份面试准备文档。文档格式参考以下结构：

```
# XX公司X面准备（地产设计管理岗）
## 一、JD 核心要点
- 显性要求：
- 隐性需求：
- 岗位真实画像：
## 二、轮次策略（X面 - 面试官角色）
- 考核重点：
- 准备策略：
## 三、公司速览
- 5 个框架问题答案
## 四、预测问题清单 + 作答框架
1. [必问/初面/终面] 问题：……
   → 框架：……
   → 要点：……
2. ...
## 五、反问准备
- 问什么：
- 为什么问：
```

### 输出格式要求
- 用 Markdown 输出
- 每个预测问题标注类型（初面必问 / 终面定义类 / 行为类等）
- 用段落 + 要点结构，不要用表格
- 整体控制在 2 页以内，不要在单个问题上过度展开

# 复盘模式完整流程（地产建筑设计管理岗）

## 输入要求
- 面试记录 / 逐字稿 / 笔记（必要）
- 用户自我体感（必要，通过 3 个问题引导）
- 如果是多轮面试中的一轮，需要上一轮的复盘记录（可选）

---

## Step 1: 信息收集
读取面试记录后，做两件事：

### 1.1 结构化提取
将面试内容按"问题-回答"逐题提取，标记出：
- 面试官的问题
- 用户的原始回答（尽量完整）
- 面试官的追问和反馈

### 1.2 初步标记
在读取过程中，标记以下类型的问题：
- **卡住的问题**：用户回答犹豫、不完整、被面试官打断或纠正
- **被认可的问题**：面试官有正向反馈（点头 / 追问细节 / 说"这个不错"）
- **意料之外的问题**：完全没有准备到的方向

---

## Step 2: 体感询问
**注意：** 这一步很重要——需要把用户的自我体感收集下来，但**不能完全相信它**。用户自我感觉"答得很好"的问题可能实际有瑕疵，而用户觉得"完蛋了"的问题可能面试官并不在意。

问用户三个问题，记录答案：

> 1. "哪道题你觉得答得最好？为什么？"
> 2. "哪道题答得最没底？"
> 3. "如果重来一次，你最想改哪道题的答法？"

---

## Step 3: 客观分析
逐题分析，每道题的输出格式如下：

```
### 问题：[面试官的原话]
**你的回答：**
[用户的回答摘要]
**面试官可能在想什么：**
[从面试官的角度分析——他为什么问这个问题？他想听到什么？你给的是他想要的吗？]
**这个问题的本质是：**
[这类问题真正在考什么能力？是行为类/认知类/压力类？]
**结构化回答模型：**
[如果是复盘，这里给出一个框架化的回答版本。如果是通用问题，给出回答框架。如果是面试中已经答得好的问题，就肯定并固化。]
```

### 分析原则
- **逐题拆解，不跳过任何一题** — 有些你以为答得好的，可能恰恰暴露了问题
- **区分"内容问题"和"表达问题"** — 是不知道答案（内容），还是知道但没说清楚（表达）？
- **区分"必问题"和"送命题"** — 有些问题答不好不影响结果，有些问题是致命伤
- **以记录为准，不受用户体感左右** — 如果用户觉得答得好的问题实际上有逻辑漏洞，你的分析必须诚实指出。你的价值是提供客观视角，不是附和用户的自我评价

---

## Step 4: 模式识别
找出用户在这场面试中暴露的**规律性卡点**。以下按优先级排列常见的卡点类型：

| 卡点类型 | 典型表现 | 判断方法 |
|---------|---------|---------|
| **定义类卡点** | 被问"什么是产品力 / 好的户型 / 容积率"时只能给朴素描述，缺乏分层与案例 | 统计定义类问题的数量和质量 |
| **方法论类卡点** | 能说"我做过成本优化"，说不清"用什么方法做的"（限额设计 / 结构优化 / 货值-成本联动） | 看回答中有没有出现方法论关键词 |
| **案例调用卡点** | 被要求举例时翻不出合适的项目，或案例太浅（只说"我管过 3 个项目"没有具体） | 看行为类问题的回答是否具体完整 |
| **跨部门协作卡点** | 被问"跟成本部 / 工程部冲突怎么办"时回答空泛，没有具体案例与方法 | 看协作类问题的回答 |
| **压力应对卡点** | 被质疑（经验不够全业态 / 薪资偏高）时直接退缩或防御 | 看压力类问题的应对方式 |
| **薪资谈判卡点** | 要价策略失误，没有留余量 | 看薪资问题的对话 |

**输出一张卡点清单：**

```
## 本次面试暴露的卡点
1. [卡点类型] — 发生在[问题X/问题Y]
   → 具体表现：
   → 建议优先解决的优先级：高/中/低
2. ...
```

---

## Step 5: 建议输出

### 5.1 如果还有下一轮
```
## 下一轮调整策略
### 本轮暴露的问题，下一轮必须在这些方面改善：
1. [具体改进点] — 如何改进
2. ...
### 下一轮的考核重点会是什么：
[根据公司面试流程推断]
### 下一轮准备方向：
[具体建议]
```

### 5.2 长期提升建议
```
## 长期成长建议
基于本轮面试暴露的卡点模式，建议在以下方向做系统性提升：
### 优先级1：[建议内容]
- 为什么重要：
- 怎么练（具体可操作的方法）：
- 建议周期：
### 优先级2：...
```

---

## 输出物模板
复盘模式的最终输出是一份逐题拆解的复盘文档。文档格式参考以下结构：

```
# XX公司X面复盘（地产设计管理岗）
## 一、整体诊断
- 面试官类型：专业型（设计/工程口）/ 业务型（营销/投资）/ 职能型（HR/成本）/ 经营型（高管）
- 整体表现评分：X/10
- 做对了什么：
- 做错了什么/可以改进的：
## 二、逐题拆解
[每道题的详细分析，按 Step 3 的格式]
## 三、卡点分析
[Step 4 输出的卡点清单]
## 四、建议
### 如果有下一轮
### 长期提升
```
